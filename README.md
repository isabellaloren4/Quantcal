# QuantCal: Post-hoc Calibration for Binary Quantifiers

Anonymized artifact repository for the paper *"QuantCal: Post-hoc Calibration
for Binary Quantifiers"* (double-blind submission).

This repository contains the code and results needed to reproduce the
experiments, including per-dataset results that were omitted from the paper for
space.

---

```
.

├── RESULTS_per_dataset.md                    # per-dataset median MAE table (106 × 13)

```

## Reproducing the experiments

The pipeline evaluates the Classify-and-Count (CC) baselines and the QuantCal
variants across **106 binary datasets** under the Artificial Prevalence Protocol
(APP), with 30 splits per dataset.


```bash
nohup python run_experiment.py > log.out 2>&1 &
```

Per-split results are written to `results/`. The median over splits for each
dataset and method is aggregated into `medianas_methods_all_exp_part4.csv`.

---

## Methods evaluated

Quantification baselines: **CC, ACC, PCC, PACC, EMQ, FM, DyS, MS, HDy, KDEyML,
MLQ**, each with a Random Forest base classifier and a calibrated variant.

**QuantCal** variants combine a base classifier (Random Forest, Logistic
Regression, or k-NN) with a regression-based post-hoc correction over
APP-generated calibration vectors, evaluated with 3, 5, and 10 calibration
points.
